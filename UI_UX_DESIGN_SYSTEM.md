# UI/UX Design System

## Colour
Medical Blue #0B6EBD
Deep Navy #073B63
Cyan #18B6C9
Soft Blue #EAF6FC
Background #F7FBFE
White #FFFFFF
Text #183B56
Muted #64748B
Success #16A34A

## Radius
Cards: 20–28px
Buttons: 12–16px
Pills: 999px

## Shadows
Use soft multi-layer shadows; avoid harsh black shadows.

## Components
Buttons:
- Primary: medical blue
- Secondary: white/outline
- Emergency: navy/green accent depending context

Cards:
- white background
- subtle border
- 20–28px radius
- hover elevation
- optional glass treatment

## Layout
Max content width: 1180–1280px
Generous vertical spacing
Strong whitespace
No cramped sections

## Visual hierarchy
1. Healthcare trust
2. Hospital identity
3. Primary conversion CTA
4. Services
5. Doctors
6. Social proof
7. Contact/location

## Mobile
Fixed bottom action bar:
Call | WhatsApp | Appointment
